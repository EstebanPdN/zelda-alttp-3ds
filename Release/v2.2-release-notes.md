## Note

Use **Original** screen mode on Old 3DS / Old 2DS for best performance. Wide mode remains available, but it can drop FPS significantly on Old 3DS because it renders a larger 400px-wide scene in software. Wide mode is recommended mainly for New 3DS.

## Changelog

- Updated the shared engine config parser so it accepts the 3DS-specific settings used by the 3DS runtime.

- Added an Old 3DS / Old 2DS runtime profile with adaptive frame pacing.
