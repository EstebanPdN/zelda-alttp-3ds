# Version 4.1-E2

Experimental pre-release. See the [changelog](../CHANGELOG.md).

Adds Japanese. The game text is the official Super Famicom cartridge: its dialogue, font,
title, file screens, name keyboard, item names, maps and intro. As in that cartridge, the
ending captions and the credits are in English and the title has no sword. The port's
menus were translated for this version; they are not Nintendo's text.

Every other language renders the same frames as v4.1-E1.

No physical Old or New 3DS has tested this build.
