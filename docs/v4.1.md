# Version 4.1

- Added Japanese game and menus, automatic language selection and a corrected title logo.
- Added direct `.zspr` skins and support for up to 512 mods.
- Fixed translations, missing characters and clipped text in Spanish, Portuguese, Italian and Russian.
- Fixed German name entry, file screens and floor labels, and the Russian Game Over title.
- Fixed German/French save-menu freezes and item-ring hangs on empty slots.
- Fixed WIDE expanded inventory and HUD/save-box text after loading across languages.
- Fairies now restore 10 hearts; Normal game asks before restarting.
- Fixed initial WIDE actor loading, distant Eyegores waking and disconnected dungeon scenery.
- Extended WIDE to Zora's River and fixed the dam's flooding window.
- Fixed outdoor parallax, mirror-wave camera/ending and lingering flute-boy ambience.
- Fixed world-map margins/corners and stale WIDE scenery after the title story.
- Corrected dungeon-item locations used by new randomizer seeds.

## Installation and compatibility

Install the CIA over the existing application or replace the Homebrew Launcher
3DSX. Existing saves, profiles and settings retain their paths. The eight
languages are English, Spanish, Portuguese, Italian, French, German, Russian
and Japanese. Each user still supplies their own compatible USA ROM.

Randomizer corrections apply to newly generated seeds. Existing saved seeds
keep their embedded placements; generate a new seed to use the corrected table.

The bridge and Master Sword clearing retain their native narrow map bounds.
Castle 4F corruption and unspecified room-transition reports remain unconfirmed;
see [bug reporting](../README.md#community-and-bug-reports) for diagnostic dumps.
Adjacent-room audio behavior is unchanged. Automated and emulator checks are
recorded locally; no new physical-console acceptance is claimed by this promotion.

See [mod installation](mods-installation.md), [randomizer support](randomizer-integration.md)
and [build documentation](development.md).
