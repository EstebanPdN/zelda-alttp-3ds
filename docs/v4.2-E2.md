## Chinese support

Merged [PR #60](https://github.com/EstebanPdN/zelda-alttp-3ds/pull/60) by frilxy. Original game translation and 16x16 font: LinkFish (@LinkFish1). Select **简体中文** in Language. This adds a ninth language while preserving the existing eight language IDs, texts and save profiles.

The package contains the Chinese language patch. It is applied locally to the user's USA ROM; no ROM or extracted game asset DAT is shipped. The pack contains 397 messages and 1163 in-game glyphs. Port menu glyphs use Fusion Pixel and GNU Unifont, with their license notices in RomFS.

## Scope and limits

This is experimental. Physical Old/New 3DS validation remains pending; emulator results are not hardware performance measurements. CIA packaging and metadata were validated; emulator execution used the 3DSX. These tests are not a full playthrough or a native-speaker review of every translated sentence.

The Chinese contribution translates dialogue and port menus. Original bitmap text such as the file/name screen and randomizer-generated English messages is not fully localized. Mods and randomizer seeds retain their own content. Existing saves/profiles are preserved.
